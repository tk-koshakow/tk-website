Performance Benchmark: Variant D1 (Interaction-Sequenced GTM)

Google Tag Manager loaded strictly upon user engagement or idle fallback

This page tests our zero-cost client-side optimization pattern: deferring Google Tag Manager container evaluation until first user interaction (scroll, touch, keydown) with a 3.5s requestIdleCallback fallback.

Measurement Methodology

We measure Mobile Lighthouse performance, First Contentful Paint (FCP), Largest Contentful Paint (LCP), Total Blocking Time (TBT), and Cumulative Layout Shift (CLS) under throttled CPU and network conditions.
