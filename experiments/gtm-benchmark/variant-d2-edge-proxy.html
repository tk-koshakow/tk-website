Performance Benchmark: Variant D2 (Edge Proxy / Server-Side Tagging)

Lightweight beacon dispatch (1.2KB) to Edge Worker / Serverless Proxy

This page tests the zero-cost Server-Side architecture: instead of loading client-side GTM (40KB+ of JavaScript), a 1.2KB native beacon dispatches the page view to an edge proxy (e.g. Cloudflare Worker free tier) which forwards to GA4/sGTM off the main thread.

Measurement Methodology

We measure Mobile Lighthouse performance, First Contentful Paint (FCP), Largest Contentful Paint (LCP), Total Blocking Time (TBT), and Cumulative Layout Shift (CLS) under throttled CPU and network conditions.
